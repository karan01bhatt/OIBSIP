# Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Oasis Infobyte Data Analytics Internship - Task 1

### 📖 Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to uncover customer purchasing behavior, product performance, sales trends, and business insights using Python.

---

## 🎯 Objective

The objective of this project is to analyze retail sales data and identify meaningful patterns that can help businesses make data-driven decisions.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook (VS Code)

---

## 📂 Dataset

Retail Sales Dataset from Kaggle

Dataset includes:
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

---

## 📊 Analysis Performed

- Data Loading and Inspection
- Missing Value Analysis
- Descriptive Statistics
- Monthly Sales Trend
- Quarterly Sales Trend
- Customer Age Distribution
- Gender Distribution
- Product Category Analysis
- Revenue Analysis
- Correlation Heatmap
- Additional Visualization
- Business Recommendations

---

## 💡 Business Insights

- Analyze monthly and quarterly sales to improve inventory planning.
- Identify high-performing product categories for better marketing.
- Understand customer demographics for targeted promotions.

---
## 📸 Output

The project includes visualizations such as:

- Monthly Sales Trend
- Quarterly Sales Trend
- Customer Age Distribution
- Gender Distribution
- Product Category Analysis
- Revenue by Product Category
- Correlation Heatmap
- Average Purchase Amount by Age
